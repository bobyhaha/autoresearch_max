Reading the chart honestly

A point below the dashed baseline is not a result. Only a point outside the grey ±2σ band is distinguishable from run-to-run seed variance — which is why the gate is a floor, not a sign test. Experiment 24 (+ WARMDOWN 0.75, Δ −0.00052) sits below baseline and was still rejected: sub-floor best-of-N is exactly the multiplicity trap.

Experiment 28 is off-scale. Tying input/output embeddings gave val_bpb 2.723 (Δ +1.798) — the tuned separate embedding/unembedding learning rates plus logit softcap require untied weights, so the run effectively diverged. Plotting it would flatten every other point into a line, so it is marked with an arrow at the top edge.
