Paired Δ = treatment − concurrent control (same seed, same data order), so this is the actual causal effect, not conflated with the seed. A point inside the ±2σ band is indistinguishable from noise. Momentum is a verified schedule-bug fix (−0.00021, sub-gate) adopted as a non-inferiority baseline correction. The four negatives are honest dead ends found cheaply through the gate. The open bet is the throughput side (fp8, fused linear+CE), whose expected effect (5–30%) is the only thing that clears a 4.4%-throughput gate.
